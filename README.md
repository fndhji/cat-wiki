# Cat Wiki — Azerty-style prototype v0.3

A compact Discord-like Cat Wiki interface inspired by the structural feel of azerty.lol,
while keeping original Cat branding, copy and assets.

## Features
- Dark theme by default
- Optional pale-blue theme
- Header card with stats/actions
- Filter pills
- Search
- Compact card grid
- Clickable detail modal
- Username Types
- Detailed legacy badge explanations
- Pricing reference
- Cat / Cat Self ecosystem
- Responsive mobile layout

## Open locally
Double-click `index.html`.

No npm install is required.
